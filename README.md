# Holo-Explorer

Holograms you control with your bare hands through the webcam: an arc reactor, a periodic table you can mix, and more. Hand tracking runs in the browser.

**Try it live:** https://augmaimaginarium.com/holo-explorer/
Part of **Augma Repo**, the free shelf of tools and studies from Augma Imaginarium: https://repo.augmaimaginarium.com

## Run it locally

It's a static web page. Serve this folder with any static server and open it in a browser:

```
npx serve .
```
